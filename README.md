# camillelimade-portfolio
Esse repositório foi criado para exibir meu perfil profissional por meio de uma página da web, de mood que contorne o que sou e o que posso oferecer no ambiente profissional. 

Meu nome é Camille Lima, eu possuo Diploma de Técnico em Desenvolvimento de Sistemas pela EEEP José Vidal Alves, onde não só tive isso como conquista, mas uma experiência profissional que foi viabilizada por meio dessa formação com o estágio curricular obrigatório e principalmente pela carga de conhecimento a qual tive acessso com uma ótima equipe de profissionais que me direcionaram para a construção dos pilares que fazem de mim a programadora e profissional de hoje.

Nesse repositório demonstro detalhes sobre quais projetos possuo e quais alimento hoje em dia, bem como certificados e habilidades no aspectos de soft e hard skills.
